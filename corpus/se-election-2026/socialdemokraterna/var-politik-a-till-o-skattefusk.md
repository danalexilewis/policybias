Skattepengar som är avsedda för vår gemensamma välfärd ska gå dit. Socialdemokraterna vill stoppa de som fifflar och smiter från att betala skatt. Det ska vara svårt att fuska, lätt att åka fast och kännbart att straffas.

Socialdemokraterna vill att varje skattekrona ska gå dit de ska inte till att finansiera kriminell verksamhet eller aggressiv skatteplanering. Vi vill skärpa kontrollerna, öka straffen för ekonomisk brottslighet och täppa till kryphål i skattesystemet. Socialdemokraterna vill stärka Skatteverket och Bolagsverket, samt återinföra nödvändiga regler för att försvåra användandet av bolag som brottsverktyg.

Skärpa straffen för ekonomisk brottslighet, införa ett nytt straff för synnerligen grova ekonomiska brott och skärpa maxstraffet från sex till tio år.

Införa en svartlistning av företag som fuskar för att utesluta dem från att få delta i offentlig upphandling.

Stärka regelverken för att motverka medhjälp till skatteundandragande och aggressiv skatteplanering.

Stärka Skatteverket för att intensifiera arbetet mot skattefusk och svartarbete, särskilt genom att öka antalet kontroller i riskbranscher.

Stärka Bolagsverket för att motverka att företag används som brottsverktyg.
