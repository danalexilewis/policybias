# Our understanding

> Smaller classes, separate help groups and gifted tracks all need extra rooms and teachers. A state takeover moves that bill to the centre. Ending profit in independent schools while keeping choice is an ownership change, not a new pedagogy.

System: Class size, ownership and screens as one staffing claim

Scenario: A full class hits an unnamed cap
Given smaller classes lead to more study calm and better results
And a maximum for pupils per class is to be introduced
When the cap binds
Then groups split or extra teachers are hired
Outcome study calm can rise where rooms exist
But the page never states the number that triggers the split

Scenario: A municipal school changes owner
Given council politicians must not be able to deprioritise school
When responsibility moves from municipalities to the state
Then funding rules and employment sit with the centre
Outcome quality is meant to vary less across the country
But local tax no longer pays the same bill, and the replacement stream is unnamed
